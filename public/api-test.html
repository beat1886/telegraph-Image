喵链 API 上传测试

通过 POST（multipart/form-data）调用 /api/upload 接口。密钥在管理页「API 接口」卡片创建，仅用于本浏览器发起请求，不会上传保存。

请求方式：POST，Content-Type 由浏览器自动设为 multipart/form-data；鉴权请求头 Authorization: Bearer <密钥>。
返回 JSON：{ "success": true, "data": [{ "url": "链接", "name": "文件名" }], "url": "首个链接" }

转存原理：
1. 页面先 fetch 该链接，取得文件字节；
2. 再组装 multipart/form-data，POST 到 /api/upload；
3. 需同源或对方允许 CORS 时才可抓取——本站链接均可正常转存，部分禁跨站的链接会提示失败。
